# CLAUDE.md

Правила роботи з агентом над цим репозиторієм. Постановка завдання: `docs/task.pdf`.

## Що це
Сервіс підтримки: вебхук хелпдеску, чернетка відповіді через LLM на базі бази знань,
модерація оператором, відправка відповіді клієнту через API хелпдеску.
Стек: Python 3.12, FastAPI, PostgreSQL 16, SQLAlchemy 2 + Alembic, Docker Compose.

## Протокол роботи
1. Перед кодом: аналіз вимог із `docs/task.pdf` і короткий план.
2. Великий код і фінальні рішення не пишуться мовчки: спочатку план, потім схвалення людини.
3. Рух крок за кроком (етап = код + перевірка + коміт), наступний етап лише після підтвердження.
4. Відступи від вимог завдання лише з прямого дозволу людини; кожне рішення має пояснення.

## Інваріанти (не ламати)
- Вебхук не викликає LLM і відповідає за мілісекунди (ліміт хелпдеску 2 с): лише запис у БД.
- Дедуплікація подій тільки обмеженнями БД (PK `webhook_events.event_id`, `ON CONFLICT`), без перевірок у коді.
- Звернення не втрачаються: вся робота через таблиці в Postgres, черга з lease (`FOR UPDATE SKIP LOCKED`).
- Ліміт LLM 60 запитів/хв на весь сервіс: лічильник у БД (`rate_limit`), а не в пам'яті процесу.
- Відповідь клієнту: один запис `outbound_replies` на звернення (UNIQUE), успіх лише `201`, заголовок `Idempotency-Key = ticket_id`.
- Режим без ключа: реальний запит до провайдера з невалідним ключем, відповідь відкидається, береться статична з затримкою 5-30 с.
- Усі зміни схеми лише через міграції Alembic.

## Команди
- Запуск: `docker compose up --build`
- Перебудова одного сервісу: `docker compose up --build -d api`
- БД: `docker compose exec db psql -U app`
- Симуляція навантаження: `python scripts/simulate.py --n 100 --dup-ratio 0.2`

## Коміти
Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`). Один логічний крок на коміт.
Без squash, без `--amend` і `rebase` після push, без force push: історія лишається «як є».

## Структура
- `app/` API, UI оператора, воркер, відправник, LLM-клієнт, пошук
- `mock_helpdesk/` мок хелпдеску з хаосом (5xx, зависання, запізнілі відповіді)
- `migrations/` Alembic, `data/articles.json` база знань, `scripts/` симуляція
